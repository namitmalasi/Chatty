# Chatty

- Developed a fullstack realtime chat application using MERN stack, implementing Socket.io for instant messaging, and live user status updates.
- Integrated secure user authentication with JWT, optimized protected routes, and implemented robust image upload & storage for sharing media in chats.
- Built a responsive, modern UI using TailwindCSS, ensuring smooth UX across devices and structuring clean, scalable frontend and backend architectures.
